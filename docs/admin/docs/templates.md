# Templates

Op deze pagina vind je templates voor gekoppelde data die andere Atlas-beheerders hebben gedeeld.
Download een template en pas het aan voor je eigen omgeving.

!!! tip "Zelf een template delen"
    Heb je een template die je wilt delen? Dien het in via
    [Template indienen](https://github.com/geo-commons/atlas/issues/new?template=template-indienen.yml).
    Je hebt hiervoor een GitHub-account nodig. Na goedkeuring verschijnt je template automatisch
    in de lijst hieronder.

!!! warning "Lever een complete set aan"
    Zorg dat je een complete set met JSON-bestanden hebt (`layers_datum.json`, `authorizations_datum.json`,
    `tables_datum.json`, `sources_datum.json`, `categories_datum.json`). Verzamel deze via de exportfunctie
    en maak er één zip-bestand van.
